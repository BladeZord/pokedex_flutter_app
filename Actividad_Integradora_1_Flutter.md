# Actividad integradora 1

## Mi Primera Aplicación en Flutter

## Objetivo

Desarrollar una aplicación básica en Flutter que permita demostrar la creación de un proyecto, el uso de widgets iniciales, la ejecución en un emulador, la instalación de un paquete externo y la publicación del proyecto en GitHub.

## Descripción

El estudiante deberá crear una aplicación sencilla sobre un tema de su elección.

### Ejemplos

- Perfil personal.
- Mi mascota.
- Mi deporte favorito.
- Mi videojuego favorito.
- Lugar turístico.
- Menú de restaurante.
- Catálogo de productos.
- Películas favoritas.
- Presentación de un emprendimiento.

La aplicación debe ser sencilla, ordenada y ejecutarse correctamente en un emulador.

## Requisitos del proyecto

### 1. Creación del proyecto Flutter

El estudiante deberá crear un proyecto Flutter desde Visual Studio Code o desde la terminal.

Ejemplo:

```bash
flutter create nombre_del_proyecto
```

### 2. Pantalla principal

La aplicación deberá tener una pantalla principal que incluya:

- `MaterialApp`.
- `Scaffold`.
- `AppBar`.
- Título de la aplicación.
- Textos informativos.
- Una imagen o ícono.
- Uso de `Column`, `Row`, `Container` o `Card`.
- Colores personalizados.
- Al menos un botón.

### 3. Interacción básica

El botón deberá realizar una acción sencilla.

#### Ejemplos

- Mostrar un mensaje.
- Cambiar un texto.
- Cambiar un color.
- Aumentar un contador.
- Mostrar u ocultar información.

No es obligatorio crear varias pantallas.

### 4. Instalación de un paquete

El estudiante deberá instalar y utilizar un paquete externo de Flutter.

Se recomienda utilizar un paquete sencillo, por ejemplo:

- `google_fonts`.
- `font_awesome_flutter`.
- `flutter_rating_bar`.
- `cached_network_image`.

El paquete debe funcionar correctamente dentro de la aplicación.

### 5. Uso de GitHub

El estudiante deberá crear un repositorio público en GitHub y subir el proyecto completo.

El repositorio deberá tener mínimo cuatro commits.

## Archivo README

El repositorio deberá contener un archivo `README.md` que documente todo el proceso.

## Evidencias de instalación

Agregar capturas de:

- Ejecución del comando `flutter doctor`.
- Proyecto creado en Visual Studio Code.
- Emulador Android funcionando.
- Aplicación ejecutándose en el emulador.
- Instalación del paquete.
- Archivo `pubspec.yaml` con el paquete agregado.
- Repositorio publicado en GitHub.

## Capturas de la aplicación

Agregar capturas de:

- Pantalla principal.
- Funcionamiento del botón.
- Uso del paquete instalado.

## Autor

Nombre completo del estudiante.

## Entregables

El estudiante deberá entregar:

1. Enlace público del repositorio de GitHub.
2. Proyecto Flutter completo.
3. Archivo `README.md`.
4. Carpeta `capturas`.
5. Historial de mínimo cuatro commits.
6. Evidencia de la aplicación ejecutándose en el emulador.
